Este proyecto implementa en Java una lista simplemente enlazada para gestionar los datos de los estudiantes del departamento de Informática, donde de cada estudiante se conoce CI, nombre, apellido, sexo, año, si es militante de la UJC y si es becado. El sistema resuelve tres requerimientos: el método Cumpleaños(String mes) devuelve el listado de nombres de los estudiantes que cumplen años en un mes determinado; el método CantMilitantes() devuelve la información de los estudiantes militantes de la UJC ordenados por año de menor a mayor; y el método CantBecados() devuelve la cantidad de estudiantes becados. El proyecto incluye las clases Estudiante, Nodo, ListaEstudiantes y un Main con casos de prueba positivos y negativos para comprobar el correcto funcionamiento de cada método.
